🎯 快速开始（选择一种方式）
─────────────────────────────────────────────────────────────────

【方式一】打包成exe（⭐推荐，最简单）

   步骤：
   1. 双击运行 "一键打包.bat"
   2. 如果提示安装Python，请先安装Python
   3. 等待打包完成（约3-5分钟）
   4. 打包完成后会自动打开输出目录
   5. 将 "dist\TemuDownloader" 文件夹整体复制给客户

   优点：
   ✓ 无需安装任何软件
   ✓ 可在任意Windows电脑运行
   ✓ 体积小巧（约30-50MB）
   ✓ 交付最简单


【方式二】直接运行Python脚本

   步骤：
   1. 确保安装了Python 3.8+
      下载：https://www.python.org/downloads/
   2. 双击运行 "run.bat"
   3. 开始使用！

   优点：
   ✓ 启动更快
   ✓ 无需打包
   ✓ 更新方便

   缺点：
   ✗ 需要安装Python环境
   ✗ 不适合交付给非技术人员


🔧 系统要求
─────────────────────────────────────────────────────────────────

操作系统：Windows 10 / Windows 11
内存：至少 4GB RAM
硬盘：至少 500MB 可用空间
网络：需要互联网连接（用于下载图片）


📖 基本使用方法
─────────────────────────────────────────────────────────────────

1. 选择输出目录
   → 点击"浏览..."按钮
   → 选择要保存图片的位置

2. 选择数据文件
   → 点击"选择文件..."按钮
   → 或直接将txt文件拖放到虚线框区域

3. 开始下载
   → 点击"开始下载"按钮
   → 观察日志区域查看进度

4. 查看结果
   → 每个产品ID会创建一个独立文件夹
   → 文件夹内包含：图片文件 + 产品描述.txt


📊 数据文件格式
─────────────────────────────────────────────────────────────────

每行格式：ID-----图片URL-----产品描述

示例：
601101871919552-----https://img.kwcdn.com/...-----Men'S Fashion 3D Funny Dog Pattern Shirt

分隔符：使用 5 个连续连字符（-----）

❓ 常见问题
─────────────────────────────────────────────────────────────────

Q: 运行时报错"找不到Python"
A: 请下载安装Python：https://www.python.org/downloads/
   安装时务必勾选 "Add Python to PATH"

Q: 打包失败
A: 
   1. 检查网络连接
   2. 确保有足够的磁盘空间
   3. 右键点击"一键打包.bat"
   4. 选择"以管理员身份运行"

Q: 下载速度慢
A: 这是正常的，取决于网络和图片数量
   可以尝试：关闭其他下载任务、使用有线网络

Q: 部分图片下载失败
A: 部分图片URL可能已失效
   查看日志中的红色错误信息
   不影响其他正常图片
